# Changelog

## [1.7.0] - 2026-08-10

### Added

- **Hide slots from set previews.** Added a button in the corner of each set pane on the Sets, Extra Sets and Custom tabs, allowing you to pick which slots are shown on the model.
- **Preview a single set piece.** Ctrl-click a piece on the Extra Sets or Custom tabs to open it in the dressing room.

### Improved

- **Toggle alert sound and chat separately.** The Set Tracker settings page has a switch for each, instead of a dropdown you had to open to see which was set.

### Fixed

- The first set you click on the Extra Sets or Custom tabs now shows its pieces straight away, instead of an undressed character.
- The Extra Sets tab shows one icon per appearance rather than one per item, so the pieces listed match the set's count.
- The Extra Sets tab no longer lists remix tier ensembles for classes that cannot wear them, such as druid tier for a monk.
- The Track on Shift-Click setting description now lists where shift-click tracking actually works: Blizzard's Sets tab, the Extra Sets tab, and the Custom tab.
